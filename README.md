# Foot Analyse

Application Android d'analyse de matchs de football : confrontations directes, les deux équipes marquent (1re et 2e mi-temps), mi-temps la plus prolifique, cotes et valeur, bankroll, journal et combinés.

Compatible Android 13, 14, 15 et 16.

## Installer sur le téléphone

1. Sur le téléphone, ouvrez : https://github.com/FranckSalem/FootAnalyse/releases/latest/download/FootAnalyse.apk
2. Touchez le fichier téléchargé, puis autorisez l'installation depuis cette source si Android le demande.

Chaque modification envoyée sur `main` reconstruit l'APK automatiquement (onglet Actions). Les nouvelles versions s'installent par-dessus l'ancienne sans perdre le journal.
